The goal of this project is to create a debugger that can be used to
dynamically evaluate how long it takes to run pieces of Python code. Ideally, 
the code will print information to the screen in the following format:

* File "/Users/sienahurwitz/Documents/Physics/Projects/2024---Islands-Representation/mydebugger.py"
| Line 1: 0.67s
| Line 2: 0.59s
| * File /Users/sienahurwitz/Documents/Physics/Projects/2024---Islands-Representation/whatever.py"....
| | Line 57: 1.23s
| | Line 58: 1.23s
| | * File /Users/sienahurwitz/Documents/Physics/Projects/2024---Islands-Representation/whatever2.py"....
| | | Line 57: 1.23s
| | | Line 58: 1.23s
| - -
| Line 9: 0.59s

So, the basic idea is as follows. As seen in "workshop.py", we can get a 
stack trace of a single line which tells us which called what in sequence. Steps as follows:

- Get initial tree or initialize it to like "<module>()" or whatever, eg "file: /Users/sienahurwitz/Documents/Hobbies/Coding/Custom Debuggers/workshop.py; func: <module>()"
- while new line:
    - get the new tree
    - if file and/or function has changed from last tree
        - x = nodes in common
        - l = length of old tree
        - m = length of new tree
        - print "| " x times followed by "- " l times to show end of trace
        - print "| " m times followe by "* " followed by new filename and function
        - set old tree = new tree
    - print "| " m times followed by line number followed by dynamic timer
